# 🪟 React Modal Popup

A simple and reusable **Modal Popup component** built with **React** that supports:
- Closing on outside click
- Manual close button
- Accept action handling
- Conditional rendering

This project demonstrates clean modal logic commonly used in real-world React applications.

---

## 🚀 Features

- 🧩 Reusable Modal component
- ❌ Close modal by clicking outside
- 🔘 Close modal using close button
- ✅ Accept action handling
- ⚛️ State management using `useState`
- 🎨 Styled with Tailwind CSS
- 🧠 Clean and readable component structure

---

## 🛠️ Tech Stack

- **React.js**
- **JavaScript (ES6+)**
- **Tailwind CSS**
